# GreenGrasp: Real-Time Environmental (AQI) Awareness & Impact Analyzer

# Project Overview
GreenGrasp is a Python-based project designed to analyze and visualize Air Quality Index (AQI) data for different Indian states. It helps users understand pollution levels, associated health hazards, and recommended preventive measures.

# Features
- View AQI data for selected states
- Graphical visualization of AQI trends
- Pollution hazard analysis
- Preventive measures suggestions
- Comparison of AQI between two states

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

# Dataset
The dataset contains AQI values for 11 Indian states across six time periods:
- Jan-Feb
- Mar-Apr
- May-Jun
- Jul-Aug
- Sep-Oct
- Nov-Dec

# How to Run
1. Install required libraries:
   ```bash
   pip install pandas numpy matplotlib
   ```
2. Run the Python script:
   ```bash
   python project.py
   ```

# Functionalities
1. Get AQI data and visualize trends
2. Analyze hazards and measures
3. Compare AQI between states
4. Exit program

# Use Case
This project can be used for:
- Educational purposes
- Environmental awareness
- Basic data analysis practice
